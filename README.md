# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. This portfolio showcases professional work, skills, and experience with beautiful animations and interactive elements.

## 🌟 Features

- **Responsive Design** - Works seamlessly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Interactive Elements** - Dynamic typing effect, smooth scrolling, hover animations
- **Sections Include:**
  - Hero section with dynamic typing effect
  - About section with personal information
  - Skills section categorized by Frontend, Backend, and Tools
  - Projects showcase with 4 featured projects
  - Experience & Education timeline
  - Contact form and information

## 🚀 Technologies Used

- HTML5
- CSS3 (with CSS Grid, Flexbox, and CSS Variables)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Poppins)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Fatal777/portfolio.git
```

2. Open the `index.html` file in your browser or use a local server:
```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve
```

3. Navigate to `http://localhost:8000` in your browser

## 🎨 Customization

You can easily customize the portfolio by editing:

- **index.html** - Update personal information, projects, skills, and experience
- **styles.css** - Modify colors, fonts, and styling by changing CSS variables
- **script.js** - Adjust animations and interactive features

### Color Scheme

The portfolio uses CSS variables for easy customization. Edit these in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    --dark-bg: #0f172a;
    /* ... more variables */
}
```

## 📱 Responsive Breakpoints

- Desktop: > 968px
- Tablet: 640px - 968px
- Mobile: < 640px

## ✨ Features in Detail

### Typing Effect
The hero section includes a dynamic typing effect that cycles through different titles.

### Smooth Scrolling
Navigation links smoothly scroll to their respective sections.

### Scroll Animations
Elements fade in as you scroll down the page using Intersection Observer API.

### Mobile Navigation
Hamburger menu for mobile devices with smooth transitions.

### Contact Form
Functional contact form with validation (can be connected to a backend).
